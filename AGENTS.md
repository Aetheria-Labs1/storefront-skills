# Storefront Skills — Agent Guide

AI workflows for building high-converting Shopify storefronts with the Lexsis AI
MCP (https://mcp.trylexsis.com/mcp).

## Skills

Canonical skills live in `skills/<name>/SKILL.md` (Agent Skills standard,
https://agentskills.io) and are also exposed at `.agents/skills/` for agents
that discover that path natively. Invoke by name, or let your agent select from
each skill's description.

The normal customer workflow is Setup → Plan → Design → Generate → Publish.
Asset Prep is an optional standalone utility. The ten public commands remain
independently invokable; explicit skips are recorded in the page manifest.

## Rules for agents working IN this repo

- `skills/` is the single source of truth. Never edit `gpt/*` — they are
  generated by `scripts/build-distributions.py`. The Claude plugin's
  `plugins/lexsis-storefront-skills/skills/` directory is also generated as a
  materialized copy because marketplace packages cannot rely on an external
  symlink target.
- After editing any skill or reference, run
  `python3 scripts/build-distributions.py` and commit the regenerated output.
- Skill frontmatter must satisfy the Agent Skills spec: `name` equals the
  directory name (≤64 chars, kebab-case); `description` ≤500 chars.
- Shared reference docs live in `skills/storefront-engine/references/`; the
  `storefront-engine` directory is not a public skill. Island schemas live in
  `references/islands/<name>/schema.json`. Do not invent island names or props.
