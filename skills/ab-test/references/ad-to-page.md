# Ad-to-page adaptation

Use the actual creative as evidence, not a generic traffic-source template.
`references/copy/message-match.md` owns the match assessment; the selected
page contract owns anatomy.

## Extract the clicked promise

1. Resolve the bound workspace, store and product. Read the exact campaign
   message and creative supplied by the merchant. For video, inspect the real
   source and select the frame the page must echo. Reconcile the audience with
   the selected `persona.md` entry.
2. Record the product/variant, hook, claimed outcome, awareness, scene, offer,
   CTA and destination. Separate verified product claims from ad language
   that still needs evidence.
3. Choose the page type through `references/page-types/_index.md`. Consult
   the matching traffic reference for entry context, not a second recipe.
4. Execute `references/workflows/_how-to-read.md`, retaining the visual and
   verbal continuity that is supported by real sources and rights.
5. Use `references/generation-protocol.md` for source compilation and the
   draft handoff. Report which creative and version were used.

A creative does not authorize copying another brand's product image,
inventing a testimonial, reproducing unverified urgency, or publishing the
result. A broken or unavailable creative is a missing input, not proof that
a generic hero matches it.
